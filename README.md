# 🏆 家庭积分奖励 · 家庭积分与游戏化任务管理系统

> 一个纯浏览器运行的家庭积分奖励与任务管理系统，数据仅存于本地 `localStorage`，零后端依赖，开箱即用。

🌐 **在线体验地址**：<https://xxmyshf.github.io/homescore/>

---

## ✨ 功能亮点

### 🖥️ 21:9 超宽屏指挥舱看板

| 功能模块 | 说明 |
|---------|------|
| 📊 **全家成员积分总览** | 爸爸、妈妈、大宝、二宝并排展示，实时积分、等级、今日变动一目了然 |
| 🔥 **连续打卡 & 今日新增** | 顶部状态栏实时展示家庭总能值、连续打卡天数、今日积分增长 |
| 🤝 **家庭同心协作大厅** | 全家协作大事件（餐后总动员、亲子共读、户外运动…），参与成员各自加分 |
| 📋 **个人任务看板** | 每日任务打卡，自动加分/扣分，支持学习自律、生活习惯、家务分担等多分类 |
| 🎁 **心愿奖品商城** | 成员专属心愿清单，积分达标即可兑换，兑换记录自动留存 |
| 📜 **实时积分动态流** | 底部滚动展示最新积分变动记录，全家动态尽收眼底 |

### ⚙️ 人物与家庭配置中心

- 👨‍👩‍👧‍👦 增删改家庭成员（姓名、头像 emoji、角色身份）
- 📝 管理每位成员的专属每日任务（自定义名称、分类、分值）
- 🎯 配置全家协作大事件（标题、描述、图标、每人奖励分值）
- 🛍️ 编辑心愿奖品（名称、所需积分、分类、图标）
- 📥 **导出数据备份** — 一键下载 JSON 备份文件
- 📤 **导入数据恢复** — 从备份文件恢复全部数据
- 🔄 重置为默认示例数据

### 🎮 游戏化体验

- 🏅 **等级成长系统** — 积分越高等级越高，从"萌新"到"传奇"
- 🔊 **Web Audio 音效合成** — 加分金币音、协作庆祝音，纯浏览器合成零外部依赖
- 🎊 **撒花庆祝动画** — 使用 [canvas-confetti](https://github.com/canvas-confetti/canvas-confetti) 实现任务完成与心愿兑换的庆祝特效
- 🌗 **深色/浅色主题** — 精心设计的视觉风格，护眼又美观
- ⛶️ **全屏看板模式** — 一键全屏，变身家庭电视墙上的指挥大屏

## 💾 数据存储说明

所有数据保存在浏览器 `localStorage` 中（键名 `homescore_store_v1`），包含：

- 成员信息（姓名、头像、角色、积分）
- 个人每日任务及完成状态
- 全家协作大事件
- 心愿奖品清单
- 积分变动流水日志
- 连续打卡统计

`store.js` 完整复刻了原后端的全部业务逻辑（积分计算、等级系统、任务管理、协作加分、心愿兑换、每日重置、备份/恢复），并通过 `HS.localFetch('/api/...')` 提供与旧版 REST API 一致的调用契约，前端代码无需感知底层存储变化。

> ⚠️ **数据安全提醒**：由于数据仅存于当前浏览器的 `localStorage`，更换设备、更换浏览器或清除浏览器数据都会导致丢失。请**定期在配置中心导出 JSON 备份**！

## 🌐 部署到 GitHub Pages

1. 将 `onlyweb` 分支推送到你的 GitHub 仓库
2. 进入仓库 **Settings → Pages**
3. **Source** 选择 `Deploy from a branch`
4. **Branch** 选择 `onlyweb`，目录选 `/(root)`，保存
5. 稍等片刻即可访问 `https://<用户名>.github.io/<仓库名>/`

> 仓库已包含 `.nojekyll` 文件，无需额外配置。
